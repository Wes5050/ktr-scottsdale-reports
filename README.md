# KTR Scottsdale reports

Google Ads dashboard for KTR Scottsdale, kept separate from other KTR locations.

- Page: `ktr-scottsdale/` (GitHub Pages)
- Data: `ktr-scottsdale/data.json`, refreshed daily at 6:50 AM AZ by `.github/workflows/refresh-scottsdale.yml` from Windsor.ai (repo secret `WINDSOR_API_KEY`).
- If a refresh fails its checks, nothing is written and the page keeps its last good data.
